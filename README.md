# Eurobot 2027 - Meta-repositorio de Software

Este repositorio contiene el script de instalación automática para el ecosistema completo de ROS 2 del robot.

## Instalación completa

Abre tu terminal y ejecuta estos tres comandos:

```bash
# 1. Clona este repositorio en tu ordenador (puede ser en cualquier carpeta temporal)
git clone https://github.com/star-uma/eurobot_software.git

# 2. Entra en la carpeta
cd eurobot_software

# 3. Ejecuta el instalador automático
./instalador.sh
```

## Instalación robot

Abre tu terminal y ejecuta estos tres comandos:

```bash
# 1. Clona este repositorio en tu ordenador (puede ser en cualquier carpeta temporal)
git clone https://github.com/star-uma/eurobot_software.git

# 2. Entra en la carpeta
cd eurobot_software

# 3. Ejecuta el instalador automático
./instalador_robot.sh
```
## Repositorios
* [eurobot2027_software_comun](https://github.com/star-uma/eurobot_software_comun.git) - Paquetes comunes tanto para robot real como simulación (descripción, visión, estrategia y navegación).
* [eurobot2027_software_real](https://github.com/star-uma/eurobot_software_real.git) - Parámetros del robot real.
* [eurobot2027_software_simulacion](https://github.com/star-uma/eurobot_software_simulacion.git) - Entornos virtuales y modelo URDF en Gazebo.
* [eurobot2027_software_firmware_esp32](https://github.com/star-uma/eurobot_software_firmware_esp32.git) - Código de bajo nivel para microcontroladores.
